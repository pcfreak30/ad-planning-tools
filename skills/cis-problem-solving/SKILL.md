# CIS Problem Solving Skill

## Overview

Systematic challenge resolution through proven problem-solving methodologies. Guides detective-style puzzle solving to identify root causes and develop effective solutions.

## Problem-Solving Methods

### Root Cause Analysis

| Method | Best For |
|--------|----------|
| **5 Whys** | Simple, linear problems |
| **Fishbone Diagram** | Multi-factor issues |
| **Fault Tree Analysis** | System reliability issues |
| **Pareto Analysis** | Prioritizing causes |

### Systems Thinking

| Method | Best For |
|--------|----------|
| **Causal Loop Diagrams** | Understanding feedback loops |
| **Stock & Flow** | Dynamic system behavior |
| **Mental Models** | Uncovering assumptions |
| **Leverage Points** | Finding high-impact interventions |

### TRIZ (Russian for "Theory of Inventive Problem Solving")

| Method | Best For |
|--------|----------|
| **Contradiction Matrix** | Technical conflicts |
| **40 Inventive Principles** | Creative solutions |
| **Su-Field Analysis** | System component issues |
| **ARIZ** | Complex problem restructuring |

### Theory of Constraints

| Method | Best For |
|--------|----------|
| **Five Focusing Steps** | System throughput issues |
| **Drum-Buffer-Rope** | Production scheduling |
| **Thinking Processes** | Logical goal structure |

## Usage

1. **Define the problem** - What specifically is broken?
2. **Gather data** - What do we know? What's unknown?
3. **Identify causes** - Use 5 Whys or Fishbone
4. **Analyze systems** - Look for feedback loops
5. **Find root cause** - Go beyond symptoms
6. **Generate solutions** - Apply TRIZ principles
7. **Implement and verify** - Test solution effectiveness

## Problem Classification

| Problem Type | Recommended Method |
|--------------|-------------------|
| Recurring issue | Root cause analysis |
| Complex system | Systems thinking |
| Technical conflict | TRIZ |
| Throughput bottleneck | Theory of Constraints |
| Multi-factor issue | Fishbone + Pareto |
