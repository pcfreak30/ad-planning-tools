# BMad Planning Workflow

## Overview
Phase 2 transforms analysis into actionable specifications. This phase produces the PRD, UX Design, and Technical Specification that guide solutioning.

## When to Use
- Analysis phase is complete
- Need to create Product Requirements Document
- Designing user experience for the product
- Planning technical architecture and specifications

## Workflow Steps

### 1. PRD Workflow
Create comprehensive Product Requirements Document:

1. Initialize workflow and discover input documents (product brief, research)
2. Define product vision and success metrics
3. Identify target users and create personas
4. Map user journeys and core workflows
5. Define functional requirements
6. Define non-functional requirements
7. Define acceptance criteria
8. Complete and validate the PRD

### 2. UX Design Workflow
Generate UX Design and UI Plan:

1. file_read PRD for requirements
2. Create user flow diagrams
3. Design information architecture
4. Define interaction patterns
5. Create UI specifications
6. Validate with user needs

### 3. Technical Specification Workflow
Create Technical Specification:

1. file_read PRD and Architecture Document
2. Define system architecture
3. Document API specifications
4. Define data models
5. Document integration points
6. Complete and validate tech spec

## Key Artifacts
- `{planning_artifacts}/prd.md` - Product Requirements Document
- `{planning_artifacts}/ux-design.md` - UX Design document
- `{planning_artifacts}/tech-spec.md` - Technical specification
